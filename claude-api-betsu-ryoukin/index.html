Claudeの月額プランがあるのに、なぜAPIは別料金？文系営業が$5で試した

AIニュースを要約する自分専用アプリを作っていたら、「従量課金」という言葉が出てきました。Claudeの月額プランとAPIは何が違うのか。$5だけチャージして試した結果、費用は6件で約6円でした。

いま、AIのニュースを毎朝要約してくれる自分専用のアプリ「AI朝刊」を、バイブコーディングで作っています。記事を自動で集めるところまでは順調でしたが、「集めた記事をClaudeに要約させる」段階で、見慣れない言葉が現れました。

従量課金。

Claudeの有料プランに入っているのに、なぜ別の料金が必要なのか。正直、「やばい道に踏み入れたのかも」と思いました。

月額プランは「店内の定額コース」、APIは「配達の業務契約」

Claudeの説明はこうでした。月額プランは、レストランの店内で食べる定額コース。人がアプリの画面で話す分には定額です。

一方このアプリは、朝5時にプログラムが自動でClaudeに要約を頼みます。これは配達の業務契約で、使った量だけ請求される。これがAPIです。同じClaudeでも、使い方で契約が分かれていたのです。

「キーを貼らないで」と何度も言われた

APIを使うには「APIキー」を発行します。Claudeは、チャージした残高にひもづいた、プリペイドカードの番号のようなものと例えてくれました。

作業中、Claudeは何度も「キーはチャットに貼らないで」と念を押してきました。履歴やファイルから漏れれば、私の残高で他人がClaudeを使えてしまうからです。お金に関わる部分だけに、慎重すぎるくらい慎重でした。

$5だけ、自動チャージはオフ

そこで、チャージは最小の$5だけにして、自動チャージはオフにしました。万一のことがあっても、被害は最大$5で止まります。「いくらまでなら失敗してもいいか」を先に決めておくわけです。

実際の費用は、6件で約6円

初めての要約では、6件のニュースが日本語の要約・要点・重要度つきで並びました。費用は約6円、1件あたり約1円です。

「従量課金」にはドキッとしましたが、仕組みを知って上限を自分で決めてしまえば、怖いものではありませんでした。
