英語の認証画面におびえながら、GitHubでMac miniとノートPCの2台体制を作った話

家ではMac mini、外ではWindowsのノートPC。作業の続きをどちらでもできるようにしたくて、GitHubを使い始めました。同じ設定を2回やるストレスと、英語だらけの画面で手が止まった記録です。

私は今、2台のパソコンでバイブコーディングをしています。

家ではMac mini。外出先ではWindowsのノートPC。机に向かえるときはMac miniでじっくり、移動の合間や出先ではノートPCで少しだけ。そんな使い分けです。

ところが、この2台体制には大きな問題がありました。

家でやった作業の「続き」が、外でできない

Mac miniで作業を進めて、翌日ノートPCを開く。すると当然ですが、昨日の作業はそこにありません。ファイルはMac miniの中にあるからです。

せっかく出先で時間ができても、続きができない。かといって、どちらか1台に決めてしまうのも不便です。

この困りごとをClaude（AnthropicのAI）に相談したところ、勧められたのが「GitHub」でした。

GitHubは、2台の間に置く「共有の保管庫」

GitHubという名前は聞いたことがありました。でも私のイメージは「エンジニアが使う、難しそうな何か」。自分には関係ないものだと思っていました。

AIの説明を聞いて、ようやく役割がわかりました。ざっくり言うと、こういうことです。

GitHub
インターネット上にある、作業ファイルの保管庫。2台のPCはどちらもここにつながる。
作業を終えるとき
今のPCから、保管庫に最新の状態を送っておく。
作業を始めるとき
もう1台のPCで、保管庫から最新の状態を受け取る。

ファイルを持ち歩くのではなく、真ん中に置き場所を作って、両方から出し入れする。仕組みそのものは、思っていたよりずっと単純でした。

同じ設定を、MacとWindowsで2回やる

仕組みはわかった。あとは準備をするだけ……と思ったのですが、ここからが大変でした。

2台で使うということは、準備も2台分です。GitHubとやり取りするための道具を入れて、自分のGitHubアカウントとつなぐ。これをMac miniで一度やって、ノートPCでもう一度やる必要がありました。

しかも、MacとWindowsでは手順が微妙に違います。道具の入れ方も違えば、画面の見た目も違う。Mac miniで一度やったから大丈夫、とはいきませんでした。

正直に言うと、これはかなりストレスでした。1回目で「やっと終わった」と思ったところに、もう1回ほぼ同じことをやる。しかも少しずつ違う。営業の仕事でいえば、同じ書類を様式違いで2回作らされるような感覚です。

一番こわかったのは、英語の認証画面

中でも手が止まったのが、GitHubの道具（GitHub CLI）を自分のアカウントとつなぐ場面でした。黒い画面に gh auth login と打ち込むと、英語の質問が次々に出てきます。

何を聞かれているのかわからない。どれを選べばいいのかもわからない。途中で英数字のコードが表示されて、ブラウザが開いて、また英語の画面。

「これ、押して大丈夫なやつ？」「何かの許可を出してしまうのでは？」と、一つひとつが不安でした。アカウントやパスワードに関わる画面だとわかっているぶん、なおさらです。

1つずつAIに聞いたら、迷わず終わった

そこでやったのは、単純なことです。画面に出てきた英語を、そのままAIに見せて「これは何を聞かれていますか？どれを選べばいいですか？」と聞く。答えを聞いて、1つ進む。また聞く。

一度に全部を理解しようとせず、目の前の1画面だけを片付けていく。これを繰り返したら、英語がほとんど読めないまま、最後まで迷わずに終わりました。

あとから振り返ると、聞かれていた内容と、私が選んだものはこうでした。

gh auth login で聞かれたことと、選んだもの

  • どこのGitHubを使う？ → 「GitHub.com」を選んだ
  • どの方式でつなぐ？ → 「HTTPS」を選んだ
  • ログインの方法は？ → 「ブラウザでログイン」を選んだ
  • 英数字のコードが表示される → 控えておき、開いたブラウザの画面に入力する
  • ブラウザで「GitHub CLIに許可を出すか」を聞かれる → 自分のアカウントであることを確認して許可する

わかってしまえば、「どこの」「どうやって」「本人ですか？」を順番に聞かれていただけ。こわがっていたのは内容ではなく、英語という見た目のほうでした。

気づき：わからない画面は「1枚ずつ」渡せばいい

今回あらためて思ったのは、知らない作業でつまずく原因は、知識の量よりも「全体が見えない不安」だということです。

全部を先に理解しようとすると、英語の画面が何枚も続くだけで心が折れます。でも、目の前の1枚だけなら、AIに聞けば必ず答えが返ってくる。1枚片付けば、次の1枚に進める。

英語が読めなくても、画面を1枚ずつAIに渡せば、ちゃんと最後までたどり着ける。

営業の現場でも、初めての業界のお客様を担当すると、専門用語がわからなくて不安になります。そういうときも、わからない言葉を1つずつ確認していけば、いつの間にか話についていけるようになる。やっていることは同じでした。

2回やるストレスは、1回目の自分へのメモで減らせる

もう一つ、次に同じことをやる人へ。2台目がつらいのは、1回目と「似ているけど少し違う」ことを、また一から進めなければいけないからです。

もしこれから2台体制を作るなら、1台目の設定をAIと進めながら「今やった手順をメモにまとめて」と頼んでおくのがおすすめです。2台目では、そのメモを見せて「これをWindowsでやるには？」と聞けば、ゼロから考え直さずに済みます。

MacとWindowsの2回戦は、正直もうやりたくありません。でも一度つないでしまえば、あとは家でも外でも、同じ作業の続きができる。その便利さは、2回分のストレスに見合うものでした。
